# Mathematical Formulation Index

> **Source of truth.** The finger design problem is defined in
> **[design/SSoT/high-level-formulation.md](../design/SSoT/high-level-formulation.md)** (paper Appendix A, Korean).
> It is written to the intended function, not to the current code. Where the code differs, the code is what changes.

It covers the morphology $M=(K,C,A,S)$, lengths and the relative flexion $q_2$, static and motion feasibility from the geometry $\mathcal G(M,\mathbf q)$, cylinder-based contact pad coverage, mechanical advantage and transmission angle, the prototype (production / CoDe) formulation, and the study formulation (Study 1).

The earlier implementation-aligned formulation is kept for provenance at
[docs/legacy/math_formulation_2026-11-17.md](legacy/math_formulation_2026-11-17.md). Do not use it as a specification.
