# Drake 엄지 집기 peg-in-hole, PIP 펴기 (36차, 실험용, 보정에서 막힘)

사용자 요청: 엄지 집기(33b의 실제 엄지 자세)로 쥔 peg를 O의 재사용 명령으로 PIP를 **펴서** 손 앞쪽의 모따기 구멍에 넣는다. 구멍은 O의 peg 경로로 놓는다.

## 설계 (`sim/drake/peg_pinch.py`)

- 33b 자세(엄지 ro −90, raa 10, mcp 45, ip −7.5°; 엄지 순응 1,525 N/m, 법선 방향으로만 움직임; 검지 MCP 72.5°). 평면 검지 하나, 조건 A, point contact, time step 0.25 ms.
- **펴기의 기구학(`pinch3_pose`와 `two_pad_drake.reference_point`):** q 0–20°에서 PIP를 1° 펼 때 distal pad 중심 근처 접촉점은 엄지 쪽으로 0.2–0.5 mm, 엄지 면을 따라 0.33–0.54 mm(검지 좌표에서 손끝 쪽·등 쪽) 움직인다. 펴기는 peg를 엄지 면을 따라 집기 앞으로 끈다. 검지와 엄지 법선의 각(마주 봄에서 어긋난 각)은 q 0, 10, 20°에서 20, 30, 40°이고, q ≈ −20°에서만 정면으로 마주 본다.
- **peg와 구멍:** peg는 capsule(반지름 3–4.5 mm, 길이 20–26 mm)이고 축이 엄지 면을 따른다. 구멍은 축선 위 앞쪽의 slot(틈 0.3–0.8 mm, 입구 모따기 45°, 벽 μ 0.3)이고, peg에는 축 방향 스프링 seat(40–80 N/m)가 걸린다. 지표는 앞끝이 입구를 지난 깊이다.

## O만의 보정: 막힘 (2026-11-25, 12개 뽑기, `logs/peg_cal0.json`, tag pgcal0)

- 검지 면이 엄지 면(peg 축)과 33–42° 기울어 있어, 검지는 peg의 옆면이 아니라 **앞쪽 끝**에만 닿는다. 손끝이 peg 앞끝에 있으므로 앞에 놓인 구멍에 손끝도 들어가야 한다.
- 결과: 12/12 뽑기에서 검지 pad가 slot 벽에 걸리고(15–22 N), peg를 놓치며(lost), peg 깊이는 0.2 mm 안쪽으로만 바뀐다. D(O)를 정의할 수 없다.
- 반대 배치(peg 축을 검지 pad를 따라 두고 엄지가 뒤끝에 닿음)도 안 된다. 펴기는 손끝을 주로 옆(엄지 쪽)으로 움직이고 축 방향으로는 10°에 약 1 mm만 가며, peg가 지골과 함께 돌아 구멍과 어긋난다.
- 지시("D(O)를 만들 수 없거나 gate 안에 들지 않으면 억지로 하지 말고 먼저 보고")에 따라 여기서 멈추고 선택지를 보고했다.
  1. 검지가 엄지와 거의 평행하게 마주 보는 다른 손 자세를 찾는다(검지 PIP 약 −20°에서 마주 봄).
  2. 집기를 빼고, 손끝이 홈 위의 peg를 PIP 펴기로 밀어 넣는다.
  3. 3차원 과제로 바꾼다.

  재설계 손은 돌리지 않았다.

## 중단 (2026-11-25, 사용자 결정)

사용자가 FK로 확인했다. 관절 한계 안에서 엄지와 검지가 평행하게 마주 보는 집기는 없다. 틈 6–9 mm에서 가장 좋은 마주 봄은 29–31°이고, 그때 thumb_ro와 thumb_ip는 한계에 붙어 있다. 위 선택지 1(평행하게 마주 보는 자세)은 이 손에서 불가능하다. 36차는 그만둔다.
