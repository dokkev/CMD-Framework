# Drake 갈고리로 당기기 (38차, 실험용, Study 3 본 실험 아님)

사용자의 새 목표에 따른 첫 후보: 과제를 약 8개까지 늘린다(지금 통과: pull-out 21, 획득 23, 손끝 원판 28z/29z, 동전 30b, 상자 세우기 35). 굽힌 손가락이 서랍 손잡이 같은 가는 막대를 proximal pad와 distal pad 사이에 걸고, 하중이 막대를 갈고리 밖으로 당긴다. 물리는 pull-out과 같지만 물체와 하중이 다르다(원기둥을 감싸 쥐는 대신 막대에 건 갈고리). 결과는 report/에 넣지 않는다.

## 38차 사전 기록 (2026-11-25, O만으로 보정, R·U는 gate만 확인, 재설계 손의 D와 E를 보기 전)

### 구현 (`sim/drake/hook_pull.py`)

- 21차 pull-out의 코드를 그대로 쓴다. `preload_match.pull_settle`(조건 A의 닫기, 안정화, Gate 0)와 `pad_shape.ramp`(같은 하중 램프와 사건, 하중–변위 곡선)다. 방향마다 안정화된 상태에서 가른다. point contact, K_Q 5, μ 1.3과 2.0.
- **배치:** 막대 반지름 ρ 5, 6, 7, 8 mm × q0 80–115°(5° 간격) = 32개다. 막대는 O의 두 pad 면이 q0에서 모두 닿는 곳에 둔다(two_pad_grasps 규칙, `dial_placements.x_contact`). 각 손에는 자기 proximal-face 좌표로 준다.
- **명령:** setpoint q0 + 10°(pull-out의 q0 + 5°보다 5° 더). 이유는 아래 보정.
- **하중 방향:** −z(손바닥 법선, 갈고리 밖으로)와 +x−z(대각선). 첫 사건(slip, loss, collapse)의 하중이 F_limit이다.
- **지표:** D = F_limit(μ 2.0) − F_limit(μ 1.3), 쌍은 (ρ, q0, 방향)이다. E(H) = |D(H) − D(O)| / |D(O)|의 중앙값.

- **잡음 바닥 (O, 명령 +0.05°, tag e38n):** 중앙 **0.00%**, 75분위 **9.09%**(54쌍). 하중 한 step(0.067 N)이 |D(O)| 중앙 0.5 N의 약 13%라 양자화가 크다.
- **R·U gate 확인:** R Gate 0 24/32, 관통 최대 0.27 mm. U Gate 0 18/32, 관통 최대 5.12 mm(8개 배치 > 1.5 mm, 안정화된 쥐기에서).
  - 알림: 보정 중 gate 수를 세려고 부른 함수(`hand_error`)가 R·U의 E를 메모리에서 계산했다. 출력한 것은 gate 수뿐이다.

### 지표와 판정 (사전, 30b·33·34·35차와 같은 형식)

- **E(H):** O의 54쌍 중 H가 두 μ 모두 Gate 0을 지나고 안정화 관통 ≤ 1.5 mm이고 한계가 있는 쌍. Gate 0 실패와 over-pressed는 따로 세고, 무한대로 둔 민감도를 보고한다.
- **판정 1:** E_R < E_U. 5, 9 mm 쌍도 보고한다.
- **판정 2:** ρ(E, Δ_contact) > 0, 순열 p < 0.05(손 18개, 2만 번, seed 0, 단측).
- **판정 3:** ρ(E, Δ_skel)을 보고하고 비교한다.
- **궤적:** held load(하중 방향 변위까지 버틴 최대 하중) 편차, R − O와 U − O, 0–5 mm 격자, μ 1.3·2.0(fig4_sync pull-out deviation 구조). 최대와 끝을 보고한다.
- **해석:** 판정 1·2가 성립하면 갈고리 걸기에서도 오차가 Δ_contact를 따른다. 잡음 75분위가 9%로 크므로, E가 이보다 크지 않은 손은 구별되지 않는다고 적는다.

### 순서와 계산

이 기록을 커밋한 뒤 나머지 16개 손을 worker 6으로 돌린다(손 셋에 43 s; 약 4분 예상). 렌더는 손바닥 위 power-grasp 카메라로 세 손가락이 막대 손잡이(양 끝에 받침과 판)를 걸어 당기는 장면이다.
