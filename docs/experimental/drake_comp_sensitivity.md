# Drake 보상 오차 민감도: 접촉 정보가 부정확할 때의 재설계 오차 (32차, 실험용, Study 3 본 실험 아님)

31차(`drake_preload.md`)는 각 손의 처음 distal 접촉력을 시뮬레이터의 참값으로 O에 맞췄다. 27차는 접촉점의 위치를 기구학으로 정확히 맞췄다. 실제 하드웨어에서는 둘 다 부정확하다: 힘 센서는 오차가 있고, 접촉점 추정은 어긋나고, encoder에는 offset이 있다. 32차는 보상에 **오차를 넣고** 재설계 오차 E가 어떻게 커지는지 본다. 결과는 report/에 넣지 않는다. 데이터는 `sim/drake/logs`에 둔다.

**가설 (사용자 문장):** "Contact-preserving redesign reduces sensitivity to imperfect contact-dependent compensation." 핵심 출력은 **교차 오차(crossover)**다: 보상이 얼마나 정확해야 기존 방식의 재설계(U)가 접촉을 보존한 재설계(R)만큼 잘하는가. 비교는 R 대 U, 그리고 손 18개에 걸친 ρ다.

| 보상 | 기준 정보 | 넣는 오차 | 수준 |
|---|---|---|---|
| F (31차, 힘 기준) | O의 처음 distal 접촉력 F* | 힘 추정 오차: 목표를 (1 + e_F) F*로 | 0, 5, 10, 20% |
| C (27차, 접촉 위치 기준) | O의 손끝 접촉점 위치 | 접촉 위치 오차: 손의 기준점을 distal 면을 따라 ±δ | 0, 0.5, 1, 2 mm |
| F와 C 모두 | — | 관절 위치 오차: 실행 명령에 encoder offset ±Δq | 0, 0.5, 1, 2° |

## 32차 사전 기록 (2026-11-24, O만으로 보정, R·U는 수렴과 관통만 확인, 오차 수준에서 재설계 손의 오차를 보기 전)

- 새 모듈이다. `preload_match.py`와 `two_pad_drake.py`는 읽기만 하고 바꾸지 않았다. 닫기, 안정화, 증분, 램프, 원판 과정, 맞춤(Illinois false position), E·FTE 계산은 `preload_match`의 함수를 그대로 부른다. 로그는 `logs/pm_{pull|disk}_{손}_{tag}.json`(31차와 같은 형식)이다.
- **재현 확인 (`comp_sensitivity.py check`, 모두 비트 단위로 같음):**

### 오차 모형 (미리 정함)

- **부호 (공통 난수):** 배치(pull-out, 14곳)마다 또는 뽑기(원판, draw 번호)마다 부호 ±1을 같은 확률로 `numpy.random.default_rng([32, seed, kind])`에서 뽑는다(kind 1 힘, 2 위치, 3 관절). **모든 손, 모든 수준이 같은 부호**를 쓴다. 크기는 수준 그대로(|e| = 수준). pull-out의 네 방향은 같은 배치이므로 같은 부호를 쓴다. 오차 종류마다 부호 열이 따로다.
- **힘 추정 오차 (F):** 손을 목표 (1 + s·수준) F*에 맞춘다. 맞춤은 31차의 맞춘 setpoint에서 시작하고 폭 2°(원판 1.5°)로 구간을 찾는다. 수렴 기준은 31차와 같다(±2% 또는 ±0.02 N, 목표에 대해). O도 오차가 있으면 맞춤을 돌린다.
- **접촉 위치 오차 (C):** 27차의 매핑 q_set,H = argmin_q ‖c_H(q) − c_O(q_O)‖에서 손의 기준점을 손끝 점(distal 좌표 x = distal_end)에서 x = distal_end + s·δ로 옮긴다(+는 손끝 쪽). O의 목표점 c_O(q_O)(O의 손끝 점)는 그대로다.
- **관절 위치 오차 (둘 다):** 실행되는 명령 전체(setpoint와 그 뒤의 증분·sweep)에 s·Δq를 더한다. 힘 맞춤은 오차 없이 한 뒤 실행 때 offset이 들어간다(맞춤과 실행 사이의 encoder 어긋남). 임피던스 이득은 두 모듈처럼 실행 명령에서 정한다.
- **O에 넣는 오차:** E의 기준은 **오차 없는 O**다(O는 원래 보정된 손). O에도 같은 오차를 넣은 run을 돌려 "오차만의 효과"(E_O, Δ_contact = 0인 손)로 보고한다. ρ에는 넣지 않는다.
- **예상되는 크기 (기구학만, O·R·U의 오차 없음):** 위치 오차는 setpoint를 조금만 바꾼다. 면을 따라 옮긴 점은 굽힘 운동의 방향과 거의 수직이기 때문이다. 2 mm에서 setpoint 변화는 pull-out(q_O 95°) 손별 0.00–0.58°, q_O 110°에서 0.00–1.35°, 원판(q_O 41°)에서 0.44–0.84°다. 힘 오차는 O에서 5%가 ±0.23°, 20%가 ±0.9° 안팎의 setpoint 변화다. 따라서 오차 종류 사이의 수준은 같은 무게가 아니다.
- **결합 조건:** 돌리지 않는다(계산 시간; 아래).

### 지표와 판정 (사전, 계열·오차 종류마다)

- **E(H)(수준, seed):** 31차와 같다. 쌍 = (배치, 방향) 또는 뽑기. 기준은 그 계열의 오차 없는 O의 D(O). 오차가 있는 H run의 점수 규칙·제외는 31차(`preload_match.pull_hand`, `disk_hand`)를 그대로 쓴다: unmatched, solver 실패, Gate 실패(pull), lost(원판)는 따로 세고 E에서 뺀다. pull C의 Gate 1은 증분이 없으므로 항상 통과로 둔다. **FTE**도 31차와 같다(pull C는 램프만의 distal 힘).
- **관통 gate:** 1.5 mm(31차 정의: pull은 안정화부터 유지 끝까지 두 pad 수직력 최대 / 2.5 kN/m, pull C는 안정화 끝; 원판은 최대 distal 힘 / 2.5 kN/m). 넘는 쌍을 **over-pressed**로 세고 E에서 뺀다. 손별·수준별 수를 보고한다.
- **(1) 곡선과 교차 오차:** 각 계열·오차 종류에서 E_R(수준), E_U(수준). d(수준) = E_U − E_R. **교차 오차**는 d ≥ 0이 처음 되는 수준이다(앞 수준과 선형 보간). 오차 0에서 이미 d ≥ 0이면 "0 (오차 없이도 R ≤ U)", 끝까지 d < 0이면 "가장 큰 수준 너머 (U가 내내 좋음)". **주 결과는 seed 1**이다. seed 2(R·U만)의 교차와 두 seed 평균 E의 교차를 함께 보고한다(뽑기 사이 퍼짐).
- **(2) 민감도 기울기:** 손마다 seed 1의 네 점(0과 세 수준)에 대한 E의 최소제곱 기울기. ρ(기울기, Δ_contact)와 ρ(기울기, Δ_skel), `analyze.spearman_perm`(손 18개, 2만 번 무작위 순열, seed 0; 단측, ρ > 0; "순열 p").
- **(3)** 수준마다 ρ(E, Δ_contact)와 순열 p(seed 1). 5, 9 mm 쌍(`h3to5_hr/hu`, `h3to9_hr/hu`)의 E도 수준마다 보고한다.
- **잡음 바닥:** 위 표의 값(pull F, disk F2는 31차 그대로).

### 해석 (사전에 고정, 계열·오차 종류마다)

- **성립:** 교차 오차가 작고(≤ 5%, ≤ 0.5 mm, ≤ 0.5°; 0 포함) **그리고** 기울기가 Δ_contact를 따른다(ρ(기울기, Δ_contact) > 0, 순열 p < 0.05). 접촉을 보존한 재설계는 부정확한 보상에 강하고, 덜 정확한 센싱으로 충분하다.
- **실패:** 가장 큰 수준까지 U가 R보다 좋다(교차가 범위 너머). 그 보상 종류와 과제에서 가설이 실패했다고 그대로 쓴다.
- **그 밖** (예: 교차는 작지만 기울기가 Δ_contact를 따르지 않음, 교차가 중간 수준, 두 seed가 다른 판정)은 섞인 결과로 있는 그대로 보고한다.
- 교차가 0인 경우(오차 없이도 R ≤ U, 예: pull C, disk F2)에는 교차 자체가 아무것도 시험하지 않는다. 이때는 R의 이점이 오차와 함께 유지·확대되는지(기울기 U ≥ R, d가 수준과 함께 커지는지)와 (2)를 함께 본다.
- **미리 알 수 있는 것:** (i) 위치 오차는 setpoint를 1° 안쪽으로만 옮기므로(위) 약한 교란이다. 위치 오차에서 곡선이 평평하면 "C는 위치 추정 오차에 둔감하다"는 결과이지 R·U 차이의 증거가 아니다. (ii) O 자신의 E_O가 이미 관절 2°에서 10–31%이므로, 큰 수준의 E는 손과 무관한 오차의 효과를 포함한다. E_O를 함께 보고한다. (iii) disk F11은 남는 뽑기가 33개이고 잡음 바닥이 4.0%(75분위 8.0%)로 31차 원판보다 크다.
