# Drake 레일 위 슬라이더를 손끝으로 끌기 (40차, 실험용, Study 3 본 실험 아님)

새 목표의 셋째 후보다. 동전 끌기(30b)에서 부드러운 탁자를 뺀 과제다. 블록이 단단한 선형 레일(x 방향 prismatic, 레일 마찰 없음) 위를 끈 스프링에 맞서 미끄러지고, 레일은 수직 스프링 위에 있어 누르는 힘을 정한다. 동전의 약함(ρ 0.55)이 탁자의 순응에서 왔는지 본다. 결과는 report/에 넣지 않는다.

## 40차 사전 기록 (2026-11-25, O만으로 보정, R·U는 gate만 확인, 재설계 손의 D와 E를 보기 전)

### 구현 (`sim/drake/slider_rail.py`)

- 평면 검지(`two_pad_drake.py` 읽기만; 조건 A, MCP 고정, 손바닥 아래, 중력). point contact, pad 2.5 kN/m, time step 0.25 ms.
- 블록(길이 20–28 mm, 높이 6 mm, 5 g)은 레일 몸체에 붙은 x 방향 prismatic joint 위에 있고, 시작점으로 끈 스프링 k_tether가 당긴다.
- 레일 몸체(20 g)는 수직 스프링 k_rail(감쇠 4 N·s/m)에 달려 있고, 자기 무게와 블록 무게는 일정한 힘이 받친다.
- 명령은 굽힘 0 → q_t(O의 손끝 면 점이 블록 윗면, 손끝 쪽 모서리에서 edge_mm 안에 닿는 각, 1 s) → q_t + sweep(4 s), 유지 1 s. 이득은 q_t에서 정한다.
- 지표는 끝에서 블록이 MCP 쪽으로 간 거리다. D = travel(μ 2.0) − travel(μ 1.3).
- lost: 닿지 않음, 또는 끝의 pad 법선력 < 0.0667 N. 관통: distal 법선력 최대 / 2.5 N/mm.

### 뽑기 (seed 40, 64개, `logs/slider_e40.json`)

`numpy.random.default_rng([40, 40])`에서 뽑는다: q_t 25–38°, 길이 20–28 mm, edge 2–5 mm, sweep 35–45°, k_tether 150–250 N/m. k_rail은 150 N/m로 고정한다.

### 지표와 판정 (사전, 30b차와 같은 형식)

- **E(H):** O의 62개 중 H가 lost 아니고 관통 ≤ 1.5 mm인 쌍. 실패는 따로 세고 무한대 민감도를 보고한다.
- **판정 1:** E_R < E_U. **판정 2:** ρ(E, Δ_contact) > 0, 순열 p < 0.05(2만 번, seed 0, 단측). **판정 3:** ρ(E, Δ_skel)을 비교한다.
- **궤적:** 블록 이동 대 sweep 시작부터의 시간, R − O와 U − O, μ 1.3·2.0. 최대와 끝을 보고한다.
- **해석:** 30b차(ρ 0.55)보다 ρ가 분명히 크면 동전의 약함은 탁자 순응의 몫이 컸다. 비슷하거나 작으면 순응이 원인이 아니다. 둘 다 그대로 적는다.
